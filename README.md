# JavaScript DOM Events Practice

A small project built while learning JavaScript fundamentals.

## Concepts Covered
- DOM Manipulation
- DOM Events
- Mouse & Pointer Events
- Event Listeners
- Event Listeners for Elements
- Dynamic Element Creation
- HTML, CSS, and JavaScript Integration

## Purpose
This project was created for learning and practicing JavaScript concepts rather than building a production-level application.

Learning one concept at a time and building consistently. 🚀
